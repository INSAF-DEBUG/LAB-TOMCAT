# Architecture LAB-TOMCAT

Ce répertoire contient le schéma d'architecture du laboratoire LAB-TOMCAT.

L'architecture présente les principaux composants du projet :

- CentOS 7
- OpenJDK 8
- Apache Tomcat 9.0.120
- Utilisateur applicatif `tomcat`
- Service `systemd`
- Application Web `demo`
- Port HTTP `8080`
