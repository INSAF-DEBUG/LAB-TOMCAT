# LAB-TOMCAT

## Présentation

Ce projet présente l'installation, la configuration et le déploiement
d'une application Web avec Apache Tomcat sur CentOS 7.

## Environnement

- Système d'exploitation : CentOS 7
- Java : OpenJDK 8
- Serveur Web : Apache Tomcat 9.0.120
- Utilisateur applicatif : tomcat
- Répertoire d'installation : /opt/tomcat
- Port HTTP : 8080
- Application : demo

## Objectifs

- Installer Apache Tomcat
- Configurer Tomcat
- Déployer une application Web
- Configurer le service systemd
- Automatiser l'installation et la configuration avec un script Shell
